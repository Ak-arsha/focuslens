Privacy & Security Architecture

🔒 Zero Server Uploads

The webcam stream is piped directly into an HTML5 <video> element in memory and passed frame-by-frame to the client-side Google MediaPipe Face Landmarker model. Not a single pixel is ever uploaded to any server or cloud API.

⚡ Pure WebAssembly + WebGL Acceleration

Face detection, blendshape calculation (jaw open, eye look vector), and 3D facial matrix estimation are computed locally on your GPU/CPU via WebAssembly (WASM).

📁 Local-Only Session Logs

Session summaries and focus scores are saved exclusively in your browser's localStorage. You can export them to CSV/JSON or wipe them anytime with one click.

🎵 Synthesized Procedural Audio

All ambient soundscapes (40Hz Binaural Beats, Rain, Brown noise) and notification chimes are synthesized on the fly via the browser's native Web Audio API oscillators and filters. Zero external audio files are downloaded.
