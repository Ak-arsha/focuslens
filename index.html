Privacy & Security Architecture

100% Client-Side Processing

Your camera stream is processed in temporary browser memory. Every video frame is analyzed directly inside your browser via MediaPipe WebAssembly. Not a single pixel is recorded or transmitted.

Zero Server Telemetry

There are no tracking cookies, analytics pixels, or cloud APIs connected to your camera. The application can run offline once cached.

Device-Only Storage

Session summaries and focus metrics are stored exclusively in your browser's private localStorage. You can export or erase this data at any time.

Synthesized Procedural Audio

Ambient soundscapes (40Hz Binaural Beats, Rain, Brown noise) are synthesized procedurally in real-time using the native HTML5 Web Audio API.
